# More Slots · 更多快捷方式

一个无需编译、可直接加载的 Chrome Manifest V3 新标签页扩展。以提供的 Chrome 截图为参考，保留白底、Google 标志、居中搜索框、圆形网站图标与右下角自定义按钮。1.0.1 已移除右上角 Gmail / Images 直达链接和搜索框下方两张 AI 卡片，保留搜索框内的 AI Mode 按钮及 Google 应用菜单。

1.1.0 改善每行居中、搜索联想及 AI Mode 交互。

1.2.0 移除按网站硬编码的图标，改为 Chrome 缓存优先；鼠标/触控板可直接从图标或名称开始拖动，并实时预览排序。

1.3.0 加入仅在本扩展新标签页显示的书签栏，支持真实 Chrome 书签、嵌套文件夹、更多书签、所有书签和深色主题。

## 安装

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目里的 **`extension` 文件夹**（包含 manifest.json 的文件夹）。
4. 打开新标签页；Chrome 若询问是否保留更改，选择保留。
5. 点击右下角「自定义 More Slots」，调整数量与列数。
6. 如需书签栏，点击页面顶部「启用书签栏」，在 Chrome 提示中允许书签权限。之后无需重复授权。

无需 npm install 或构建。`more-slots.zip` 是相同扩展文件的便携包；换电脑时先解压，再加载解压后的文件夹。保留已加载的文件夹，否则扩展会无法使用。它是本地安装包，尚未发布到 Chrome 网上应用店。

从 GitHub 下载源码时，可使用 Code → Download ZIP，解压后选择里面的 `extension` 子文件夹。源码仓库不保存生成的安装 ZIP；如需自行打包，将 `extension` 内的文件压缩即可。

已安装旧版时：在 `chrome://extensions` 找到 More Slots，点击该扩展的刷新按钮，然后重新打开新标签页。使用相同的 extension 文件夹更新即可保留本机快捷方式与设置，无需卸载。1.0.0 / 1.0.1 导出的备份仍可导入。1.1.0 新增 Google 联想域名的访问权限，如果 Chrome 提示权限变更，需要允许后重新启用扩展。

## 功能

`extension/manifest.json` 已内置固定公钥，**直接加载 `extension` 文件夹**即可得到固定 ID `fhohijfjoehgofnnnghbgiglmaagemni`，无需构建或使用 ZIP。安装包只保留 `more-slots.zip`，内容与 `extension` 文件夹一致。首次从旧 ID 切换时先导出配置，再导入一次；详见[固定 ID 说明](docs/fixed-id.md)。

- 新标签页顶部显示真实 Chrome 书签栏。读取书签及文件夹，点击或悬停展开菜单，支持嵌套目录和键盘操作；空间不足时收进「更多书签」，「所有书签」可查看其他目录及打开 Chrome 书签管理器。
- 书签变化会自动更新。现代 Chrome 的账号与本机书签目录按元数据识别，重名目录标注来源；旧版 Chrome 使用兼容路径。
- 可在设置中关闭页内书签栏。页面离开后它自然消失，不改变 Chrome 全局书签栏的显示设置。书签权限为可选权限，代码仅使用读取方法和变化事件，不创建、修改、删除或同步原生书签；书签数据不写入快捷方式备份。

- 默认显示 24 个快捷方式，可设为 1–1000；**设为 0 显示全部**。超出的快捷方式通过「显示更多」展开。
- 每行可设置 3–12 列，窄窗口会自动减少列数。每一行按实际图标数量独立居中，包括未满的最后一行；添加按钮也计入每行数量。
- 不会为了凑满数量显示空格子；点击「添加快捷方式」即可继续添加。最多保存 1000 个网站。
- 新增、编辑、删除；删除后 10 秒内可撤销。鼠标或桌面触控板按住图标/名称移动即可排序，支持实时换位、跨行移动及靠近窗口边缘自动滚动，松手保存。Esc、拖出区域松手或窗口失焦会取消。也可通过菜单「向前移动 / 向后移动」排序；触屏保留滚动及菜单排序。
- 鼠标悬停显示三点菜单，也可右键打开；支持 Tab、方向键、Escape 操作。
- 搜索框支持 Google 搜索与直接输入网址。聚焦时展开本机最近搜索和快捷方式，输入时匹配网站名称/网址并获取 Google 实时联想。支持鼠标、方向键、Enter、Esc 及中文输入法。
- 普通 Enter 执行普通搜索或打开网址；点击 AI Mode 时，有文字则携带问题进入 AI 搜索，留空则打开 `https://www.google.com/ai`，按钮会显示「正在打开…」。AI Mode 的实际服务可用性仍取决于 Google 账号、地区和网络。[Google 使用说明](https://support.google.com/websearch/answer/16011537)
- Google 联想服务失败或超时会保留本机建议，并提示「Google 联想暂不可用」，不影响正常搜索。Lens 跳转到 Google 图片搜索服务。
- 深色、浅色、跟随系统；可选择在新标签页打开快捷方式。
- JSON 备份导出和导入。导入前会显示替换确认，并校验网址、数据结构和文件大小。
- 同一浏览器资料中的多个新标签页会同步快捷方式与设置。

## 与 Chrome 原生页面的区别

Chrome 提供的方式是使用 `chrome_url_overrides.newtab` 替换新标签页，无法直接给原生网格扩容。[官方说明](https://developer.chrome.com/docs/extensions/develop/ui/override-chrome-pages)

- 当前页面是独立扩展，右下角使用 More Slots 名称，未冒充 Chrome 自带页面；未修改浏览器地址栏的默认搜索引擎。
- 无法自动读取原生快捷方式、Google 账号头像、原生 Doodle、原生个性化推荐或 Chrome 主题。头像位置提供 Google 账号入口，应用菜单为常用 Google 服务链接。
- 预置截图中的六个网站作为可编辑的起点，其中 BMF 暂按图标指向 bilibili.com，可自行修改。
- 麦克风按钮跳转 Google 页面，需在 Google 页面点击麦克风使用语音搜索；不会在扩展内直接录音。Lens 也在其独立网页使用。
- AI Mode、Gemini 等服务是否可用取决于地区、账号和 Google 自身服务。
- 数据仅保存在本机，不使用 Chrome 账号云同步。卸载前请先导出备份；关闭扩展即可恢复 Chrome 原生新标签页。
- Chrome 无痕窗口不支持覆盖新标签页。

## 底部扩展信息栏与网站图标

某些 Chrome 版本会在新标签页底部额外显示带有 More Slots 扩展名称和「Customize Chrome」按钮的整条页脚。它由浏览器绘制，在扩展页面之外；上方「自定义 More Slots」才是本扩展的设置按钮。

可以点击底栏中的「Customize Chrome」，在 Chrome 侧栏寻找「Footer / 页脚」及「Show footer on New Tab page / 在新标签页上显示页脚」开关；如果当前版本提供并允许切换，可从那里关闭。扩展本身不能通过 CSS 删除浏览器的这条栏，页脚也不由本扩展的设置控制。[Chromium 页脚实现](https://raw.githubusercontent.com/chromium/chromium/main/chrome/browser/ui/views/new_tab_footer/footer_controller.cc)

1.2.0 已删除此前打包的 B 站、知乎等六个网站图标。所有网站使用相同规则，不再按名称或域名强制指定品牌图片：先读取 Chrome 当前资料中的精确网址 favicon 缓存，再尝试站点根地址缓存；无缓存或返回 Chrome 默认地球占位图时，尝试该网站的 `/favicon.ico`，都失败则显示名称首字。

这能避免扩展里的旧图片盖过 Chrome 已缓存的图标，但不保证 Mac、Windows 或两个不同浏览器资料中的图标像素完全相同：网站可能更新图标，不同设备缓存及原生新标签页选用的图标资源也可能不同。若看到首字占位图，可先访问一次对应网站，再重新打开新标签页。扩展不会从另一台设备同步 favicon 缓存。

## 隐私与资源

申请 `storage`、`favicon` 两项 API 权限，以及 `https://suggestqueries.google.com/*` 的域名访问权限，用于 Google 实时联想。另声明可选的 `bookmarks` 权限，仅在你点击「启用书签栏」并授权后读取书签，用于此页面的展示。无后台进程、无统计、无广告、无远程脚本、无浏览历史读取权限。

Google 实时联想默认开启：输入搜索词时会向 Google 联想服务发送输入内容，可在「自定义 More Slots → Google 实时联想」关闭；关闭后仅使用本机建议。请求有防抖、取消与超时处理，不携带账号 Cookie，直接网址和超过 200 字的内容不请求联想。服务返回数据只作为文本显示，不执行 HTML 或脚本。该联想端点可能受 Google 后续变更影响，失败时会自动回退本机建议。

最近搜索只记录在本扩展搜索框提交的搜索词，最多保留 50 条，仅存在本机；下拉列表中可点击「清除最近搜索」。它不读取 Chrome 历史，也不随快捷方式备份导出。

Google 标志和扩展自身图标打包到本地。网站图标使用 Chrome 的 favicon API；缺失时直接请求该网站的 `/favicon.ico`，不通过 Google favicon 服务或其他第三方代取图片，且不附带页面路径或搜索词。扩展不会把用户快捷方式发送到自建服务；Chrome 如何取得和缓存图标由浏览器管理。[favicon API 说明](https://developer.chrome.com/docs/extensions/how-to/ui/favicons)

Google 与网站标志属于其各自权利人，本项目并非 Google 官方产品。

## 开发与验证

原生 HTML/CSS/JavaScript 模块，无运行时依赖。

```powershell
npm test
npm run check
```

已使用 Playwright 在本机 Chrome 测试页面交互，并在隔离的 Chromium 扩展环境测试实际 Manifest V3 加载、`chrome://newtab` 替换、`chrome.storage.local` 保存、favicon API 和多标签页同步。未修改个人 Chrome 配置。

验证过新增、编辑、移除、撤销、拖动和菜单排序、数量/列数设置、展开收起、深色主题、刷新保存、备份导出、非法备份拒绝、有效备份恢复及搜索提交。1864×949 桌面和 390×844 窄窗口均检查了布局，无页面运行错误；页面测试中的搜索请求被拦截验证 URL，未验证外部 Google 服务的实际可用性。

1.1.0 使用隔离 Chromium 扩展环境检查了 108 种布局组合（4 种窗口宽度 × 3 种列数 × 9 种快捷方式数量），逐行测量中心位置，未满行与完整行均对齐搜索框中心，且不超出配置列数。还验证了本机与远程联想、方向键选择、过期响应丢弃、普通 Enter 与 AI 搜索区分、AI 空输入跳转、历史保存/清除、中文输入法、联想开关和模拟服务失败。普通搜索与 AI 跳转请求由测试拦截，验证的是目标 URL；Google 实际 AI 回答与账号个性化推荐不在测试范围内。

Google 联想还在扩展实际运行环境中做了真实网络验证，测试词 git 返回 HTTP 200 与 15 条候选；最终联想截图使用真实返回数据。模拟 503 的测试会产生预期的网络错误日志，页面能正常回退，未出现 JavaScript 运行异常。当前没有 Browser 测试插件，页面交互与截图均通过 Playwright 完成。

1.2.0 用隔离 Chromium 资料及本机测试站点验证了实际 favicon 缓存优先、默认地球占位图识别和网站 favicon 回退。排序测试使用真实 `mouse.move → mouse.down → mouse.move → mouse.up`，从图片和文字本身开始，检查了实时 DOM 换位、跨行与反向移动、刷新保存、Esc/区域外取消、折叠状态下隐藏网站顺序保持、编辑菜单与普通点击。1280×900 桌面及 390×844 窄窗口完成截图检查，无页面运行异常。尚未在 Mac 实机测试；本机测试网站使用扩展图标作为可辨认的 favicon 测试素材，并非对用户的 Mac 缓存截图做像素匹配。

1.3.0 检查了未授权提示、显示开关保存、真实书签树、嵌套菜单、方向键和 Esc、链接打开、书签变化后的即时更新、深色主题、窄窗口溢出菜单与「所有书签」。桌面 1864×949、窄窗口 390×844 均完成截图检查，无页面运行异常。授权后的 API 测试使用独立扩展副本在测试资料中预授书签权限，没有代用户接受个人浏览器的授权提示。当前版本的书签栏只读，不支持在页内编辑/拖动原生书签，不执行 javascript/data 书签。
